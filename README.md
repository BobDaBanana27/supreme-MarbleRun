 # Marble Run

## The current build

The recommended model is **[MarbleRun_Vortex.stl](MarbleRun_Vortex.stl)**. It is a single, centered marble run with a wide starting funnel, a short bumpy section, three open turns, a downhill switchback, and a cup at the end. The track stays open instead of curling into a tight spiral.

The STL is already built and ready to import into a slicer or CAD program; you do not need to run the generator script.

## Size and marble fit

- Base footprint: **220 × 220 mm**
- Overall height: **about 55 mm**
- Track lane: **20 mm wide**
- Designed for: **16 mm marbles**
- Track floor: **3.2 mm thick**
- Track walls: **2.4 mm thick**
- Finish: **44 mm diameter catch cup**

The model fills a 220 × 220 mm footprint, so check your printer’s usable bed area before slicing. The cup is part of the same model as the platform and track.

## Earlier versions and Fusion 360 files

This folder also contains the earlier, simpler assembled run and the original eight-chunk Fusion 360 materials. Those are kept as project history. For the revised centered design with the catch cup, use **MarbleRun_Vortex.stl**.
