 # Marble Run

## The current build

The recommended model is **(MarbleRun_Vortex-compressed.glb)**. 

The STL was too big so I had to compress it using one of those online sites. The glb file is ready to be put into a slicer or CAD program.

## Size and marble fit

- Base footprint: **220 × 220 mm**
- Overall height: **about 55 mm**
- Track lane: **20 mm wide**
- Designed for: **16 mm marbles**
- Track floor: **3.2 mm thick**
- Track walls: **2.4 mm thick**
- Finish: **44 mm diameter catch cup**

The model fills a 220 × 220 mm footprint, so check your printer’s usable bed area before slicing. The cup is part of the same model as the platform and track.

3. Quarter turn: I shaped a 90-degree curved section with the same channel dimensions as the straight piece. It lets the run change direction without making a sharp corner the marble would hit.

4. Entry funnel: I made a wide opening that narrows down to the track. Its floor slopes down 16 mm, so the marble gets moving and enters a straight section at the right height.

![image](https://halflife.hackclub-assets.com/hackclub-half-life/sessions/fpT4vKaaCxCaCu9yi3OynxGXkAPlXNzI/2fc875ce951d9ea4049480aaef629dcb1237a8e2c73c88f043d2211c677ad77a.png)
5. Tilt wedge: I added a separate ramp that can sit under a straight channel to give it more slope. It’s an optional piece for trying a different layout.

6. Support pedestal: I made a tall support with guide rails on top to hold a track section in place. It’s useful for a raised layout, though the basic tabletop route doesn’t need it.
